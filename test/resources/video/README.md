# Video test assets

Copy these files from `vglib_examples/data/video` into this directory, or set
`VULKANIZER_VIDEO_DIR`/`--video-dir` to the existing example asset directory:

- `2616637-hd_1920_1080_30fps.mp4`
- `3116737-hd_1920_1080_25fps.mp4` (cat)
- `855289-hd_1920_1080_25fps.mp4` (squirrel)

The MP4 files are intentionally covered by the repository's existing media ignore
rule. See `docs/video.md` for the player and verification commands.
