# MultiUVTest

Converted from Khronos glTF-Sample-Assets, Models/MultiUVTest/glTF/MultiUVTest.gltf.
Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/MultiUVTest
Model by Hilo 3D, copyright 2017, CC BY 4.0. The glTF logo is attributed to Khronos Group. See LICENSE.md. Changes: converted geometry/materials into vkmesh/vkmat/vkbounds and images into embedded KTX2 textures.

This scene has one mesh instance and two UV sets. Run vulkanizer_multi_uv_test for graphics, or add --ray-traced for ray tracing. Both use the orbit camera and studio_small_09_2k.hdr environment. --samples, --blur, --no-ibl, --validation, --timeout and --screenshot are supported by the shared viewer.

CTest registers vulkanizer_multi_uv_graphics and vulkanizer_multi_uv_ray_traced.
