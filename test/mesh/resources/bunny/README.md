# Stanford Bunny

`bunny.glb` is the uncompressed glTF 2.0 Stanford Bunny distributed in
https://github.com/erichlof/Babylon.js-PathTracing-Renderer/blob/main/models/StanfordBunny.glb

Downloaded 2026-10-01. The source repository distributes its contents under CC0 1.0; a copy is in `LICENSE`.
The original scan is credited to the Stanford University Computer Graphics Laboratory:
https://graphics.stanford.edu/data/3Dscanrep/

The SBT example converts this asset through Vulkanizer's existing glTF importer into its build directory.
