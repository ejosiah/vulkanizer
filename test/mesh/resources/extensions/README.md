# glTF extension samples

Converted from [Khronos glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models). Geometry/materials were converted to Vulkanizer caches and textures to embedded KTX2 payloads; the source assets are otherwise unchanged. Original metadata and source attribution are retained beside each cache.
